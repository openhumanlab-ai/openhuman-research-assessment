# Submission

Return the repository or a ZIP through the channel agreed with Ram or Alessandro. Git is optional for ZIP submissions. Include the following:

1. **One research note**, approximately 2–3 pages. Cover the question, source selection and synthesis, evaluation, results, limitations, and recommendation. Include links to the evidence you rely on; a compact source table is useful if it helps.
2. **Supporting experiment files:** your brief plan saved before the main pilot, inputs, prompts/settings, raw outputs including failures, and runnable analysis with instructions. The plan can be a few paragraphs in your notebook. Record consequential later changes. We should reproduce your reported calculations from saved outputs without API calls.
3. **Prompting history:** assessment-related research and coding assistant conversations, including your prompts, visible AI responses, and follow-up instructions. This is required alongside experimental API logs; see [ai-history/README.md](ai-history/README.md).

Add a few lines to the note or notebook covering active time, interruptions, important clarifications/decisions, and unfinished work. A separate process report is unnecessary.

Reading the supplied pack and setup are outside the timer. Stop research, experiments, analysis, and writing at four hours of active work. Final export/upload can happen afterwards; it is not extra research time.

Check that claims trace to sources or saved results, that analysis instructions work, and that assistant-history files are included. Exclude `.env`, credentials, unrelated conversations, and virtual environments. If submitting through Git, commit the deliverables; they are not ignored by the starter.

Expect a short discussion of one paper's methods, your evaluation, a result, and an important AI-assisted decision. A negative or inconclusive pilot can be strong work.
