# Save prompting history from the start

Arrange this during untimed setup. Submit only sessions related to this assessment.

## Assistant conversations

Use a native export or a chronological Markdown, text, HTML, or JSON transcript. Include your prompts and supplied context, visible assistant responses, follow-up instructions/corrections, and visible tool actions where available. Record tool/model names when known and preserve session order.

Save these files under `ai-history/`. Hidden model reasoning and private system instructions are not requested. You do not need to rewrite or annotate every exchange. If an export is incomplete, state the gap and retain what you can as you work; do not present reconstructed conversations as original logs. State if you used no assistant.

Redact credentials and unrelated private information, including in attachments. Mark redactions without including the removed values. Final export/upload can happen outside the timer; continue saving the assessment sessions throughout the work.

## Experimental calls

Separately retain the exact model prompts, settings, and outputs. The supplied runner saves these automatically. Experimental logs do not replace research/coding assistant conversations.

We assess whether you direct and check the work and can explain your decisions. AI may propose the approach or write the code. Prompt length/count and rejecting suggestions earn no automatic credit. Explain important decisions made outside the conversation in the process lines in your note or notebook. An incomplete export is missing evidence, not automatic proof of poor ownership.
